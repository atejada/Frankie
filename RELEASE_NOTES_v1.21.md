# Frankie v1.21 — "The Book Edition" 📖

- **Image sprites in `frankiecanvas`.** `load_image(path)` loads a PNG/JPEG/GIF; `draw_image(g, x, y, image, w:, h:)` draws it at cell coordinates, cached client-side after the first frame. `frankiegame` (terminal) gets matching calls that render a `▒` placeholder block, so cross-engine code compiles against either stitch.
- **WebAudio synth API.** `synth_play(g, freq:, wave:, dur:, gain:)` plays a real oscillator tone (sine/square/sawtooth/triangle) in every connected browser. `game_beep` is now a thin wrapper over it — fully backward compatible. `frankiegame` maps `synth_play` to the terminal bell.
- **New stdlib primitive: `file_read_base64(path)`.** Binary-safe file read + Base64 encode in one call — what `load_image` uses under the hood, and generally useful for embedding images/audio/zips as text.
- **Documentation pass.** `SPEC.md` corrected (it claimed `return` was required — implicit last-expression return has worked since v1.11) and extended with the v1.19 gradual type-annotation grammar it was missing. `CLAUDE.md` updated (was stuck at v1.16.2, missing the game-engine stitches from its own list). README's doc index was missing four versions' worth of rows (v1.17–v1.20) — restored.
- **Fixed a data-loss bug in `frankiec fmt`.** A single-statement block whose body was an assignment or a postfix-`if`/`unless` (e.g. `game["shots"].each do |s| hit = true if collide?(...) end`) got silently formatted into `do |s| nil end` — the actual logic was discarded. `_is_stmt_only()` in `frankie_fmt.py` was missing several statement node types, so the formatter tried to render them as expressions and fell back to `nil`. Found while updating the Zombie Invaders showcase; verified fixed by comparing compiled Python output before/after reformatting (byte-identical). If you've run `frankiec fmt --write` on code with this pattern before v1.21, worth a diff review.
- **🧊 Language freeze.** v1.21 is the last feature release for a while — the language is frozen while "The Book of Frankie" gets written against this exact version. Patch releases (bug fixes, doc corrections) continue; new syntax and stdlib/stitch signature changes are on hold.
