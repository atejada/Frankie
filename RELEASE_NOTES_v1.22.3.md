# Frankie v1.22.3 — patch release 🐛

- **`frankiec fmt` no longer deletes your comments.** Comments were dropped as trivia during tokenization and never reached the AST, so the AST-based formatter had no way to preserve them — every `fmt --write` silently erased every `#`/`##` comment in the file, doc comments included. The lexer now keeps a side record of every comment it skips; `fmt` re-attaches each one to its neighboring statement by source line, both leading (`## doc comment` above a `def`) and trailing (`x = 5  # like this`) styles, plus a comment block at the very end of a file. The one case it still can't place — a comment dangling at the end of a block with nothing after it before `end` — now prints a warning with the line number instead of disappearing without a trace.
- **`frankiec fmt` no longer silently changes what your code does.** Separately, while testing the fix above: `fmt` had no operator-precedence awareness when reprinting expressions, so it could drop parentheses that were load-bearing. `sleep((budget - elapsed) / 1000.0)` came back as `sleep(budget - elapsed / 1000.0)` — an actual different computation, found in both `frankiegame.fk`'s and `frankiecanvas.fk`'s frame loops. Same issue hit range bounds: `0..(n - suffix.length - 1)` in `frankiestring.fk` lost its parens and re-parsed as `(0..n) - suffix.length - 1` on a second `fmt` pass. Fixed with a real precedence table matching the parser's, so an operand is now parenthesized whenever dropping the parens would let it re-bind differently on re-parse. Verified behavior-identical (ran before/after `fmt`, diffed output) on every affected file.
- **Restored the doc comments `frankiegame.fk` and `frankiecanvas.fk` lost** to the comment bug during the v1.21.0 work (shipped without them through v1.22.2) — recovered from the last comment-intact version plus new comments for what v1.21 added. Code itself untouched: diffs are comment/blank lines only.
- Verified across the whole `stitches/`/`examples/` tree (970 comment lines): zero comment loss, zero instability across repeated `fmt --write`, every file still passes `check`, every test suite still green.

This is a bug-fix-only release under the language freeze — no new syntax, no stdlib changes.
