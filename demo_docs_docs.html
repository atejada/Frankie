🔧 haversine(p1, p2, radius: 6371.0)
demo_docs.fk:9
Computes the great-circle distance between two points on a sphere.
Parameters
  • p1 — First point, a {lat, lon} hash in degrees
  • p2 — Second point, a {lat, lon} hash in degrees
  • radius — Sphere radius (defaults to Earth's, in km)
Returns
Float distance in the same units as radius
Example
haversine({lat: 52.5, lon: 13.4}, {lat: 48.8, lon: 2.3})
# => 878.4
